# TrustworthyIoMT-Explanation-Fidelity-Trade-offs-in-Compressed-Cardiac-Risk-Screening-Models
SHAP-based explanation-fidelity analysis of compressed (float16, int8, pruned+int8) TFLite DNN models for cardiac risk screening on IoMT edge hardware. Benchmarks accuracy, latency, size, Spearman correlation and top-k Jaccard drift; informs a three-tier edge-cloud IoMT architecture.
